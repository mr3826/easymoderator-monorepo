Architecture Findings

sanitizeSettings allowlist vs preserve-all

The reusable mergeAndSanitizeSettings helper now deep-merges patches, preserves existing persisted domains, removes new unapproved top-level keys, and validates known nested sections before each relevant settings write.

STATUS: REMEDIATED — writer and nested-merge regression coverage added

Settings JSONB as multi-purpose store

Single JSONB column stores AI settings, BD settings, business info, branding, onboarding state, and platform priorities. Concurrent writes and partial updates are fragile. No transactional isolation between domains.

RECOMMENDATION: CHANGE_LATER — safe merge is in place; dedicated columns remain an architectural follow-up

Frontend subscription features fail-open

useSubscriptionFeatures() now normalizes the subscription envelope and returns an all-false locked set for rejected, missing, or malformed entitlement data. FeatureGate distinguishes unavailable entitlements from a confirmed plan restriction.

STATUS: REMEDIATED — frontend hook and gate regression coverage added
